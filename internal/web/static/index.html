The camera history window is also how far back the scrub bar reaches. Prints kept hold their footage past that window, thinned to one frame every 10 seconds. Auto-off countdowns already running keep the window they started with. The event log keeps the oldest entries only while it is under its size; printer reports are much the largest part of it, so how far back it reaches depends on how much the printer has to say. The figure counts what the log itself holds, not the size of the database file, which also holds the camera buffer and does not shrink on disk when entries go. The database cap is the one bound on that file: 0 switches it off, and with it set the oldest data goes — frames and log entries alike, whichever is older — until the file is under it. It overrules everything above, so it will delete footage that Prints kept was holding on to. It measures the database file, not the small write-ahead file beside it. Staying logged in counts from the last time the page was used, so a phone on the home screen only has to log in again after that long away from it.
